데스크 고양이 로봇에 클라우드 두뇌와 다중 인격 달아주기 2026-11-16

Raspberry Pi Pico W + Google Sheets + Gemini Flash Lite 초경량 에이전트 파이프라인 구축기

1. 로컬 LLM 삽질에서 '초경량 3단 분리'로
어제 Freenove 이족보행 로봇 키트를 책상 위 고양이 시계 봇으로 개조한 데 이어, 오늘은 녀석에게 진짜 '말하는 두뇌'를 붙여주기로 했다.
예전에 라즈베리 파이 5(16GB)에 로컬 AI 서버를 직접 올려보겠다고 끙끙대다가 발열과 느린 응답 속도에 질려 접었던 기억이 있다.
작은 엣지 디바이스에 모든 걸 우겨 넣으려 하면 배보다 배꼽이 커진다. 대신 이번엔 철저하게 역할 분담을 택했다.

- 두뇌 (Google Apps Script): 시간대별로 깨어나 상황을 판단하고 구글 캘린더 일정을 확인하는 규칙 엔진.
- 작가 (Gemini API): 상황 지시를 받아 감정 태그와 36자 이내 대문자 영문 대사(MOOD|TEXT)를 빠르게 뽑아주는 생성기.
- 전광판 버퍼 (Google Sheets): 클라우드와 하드웨어 사이의 초경량 메시지 버퍼(A1 셀). A2 셀에 직접 메모를 적으면 즉시 대사를 덮어쓸 수 있는 원격 리모컨 역할도 겸한다.
- 단말기 (Raspberry Pi Pico W): 무거운 로컬 추론이나 LLM JSON 파싱 없이, 시트의 텍스트 한 줄만 긁어와 8x16 LED 매트릭스 표정과 부저·서보모터 움직임만 연기하는 순수 출력 장치.



2. 시간대별 다중 페르소나 스위칭
단순히 정해진 멘트만 읊으면 금방 질리니까, Apps Script가 현재 시각을 체크해 시간대마다 로봇의 인격(모드)을 바꾸도록 프롬프트 파이프라인을 짰다.

- 08:00 ~ 10:00 (모닝 브리핑): 구글 캘린더에서 오늘 일정을 읽어 가장 중요한 스케줄을 요약해 준다.
- 13:00 ~ 15:00 (SecUnit 모드): 나른한 오후에는 SF 소설 《머더봇 다이어리》의 보안 안드로이드처럼 인간들을 무심하게 관찰하는 시니컬한 로그를 띄운다.
- 20:00 ~ 23:59 (SYS://MARSKO 모드): 밤이 되면 심야 창작과 해킹 프로토콜에 돌입한 사이버펑크 터미널 상태로 전환된다.
- 그 외 시간: 책상 위를 지키는 다정한 이족보행 고양이 로봇 모드.



3. API 쿼터 최적화와 디버깅
처음에는 Gemini 3.8 Flash 모델을 연결했는데, 무료 티어 일일 호출 한도(RPD)가 20회뿐이라 트리거를 자주 돌리면 금방 바닥날 판이었다.
사용 가능한 모델 리스트와 한도를 다시 확인해 보니 Flash Lite 계열이 일일 500회 한도로 훨씬 넉넉했다.
모델 호출 경로를 표시 이름 대신 정확한 API ID(models/gemini-3.5-flash-lite)로 수정하고, 한도 초과나 오류 시 models/gemini-3.1-flash-lite로 자동 넘어가는 이중 폴백(Fallback) 구조를 적용했다.
두 모델을 합치면 하루 최대 1,000회 호출이 가능해져 5~15분 간격 트리거도 여유롭게 돌아간다.
실제로 어떤 모델이 호출되었는지 한눈에 확인하기 위해 시트 B1 셀에 [16:33:38] gemini-3.5-flash-lite 형태로 실시간 상태 로그를 남기는 디버깅 코드도 추가했다.



4. 메모
예전엔 개인 홈페이지 하나 운영하려고 호스팅 비용 내고 SSL 인증서 갱신하느라 진을 뺐는데, GitHub Pages로 옮기고 나니 무료 HTTPS 환경은 물론이고 코드 수정부터 작업 일지 정리까지 AI 에이전트들과 함께 막힘없이 이어진다.
하드웨어는 가볍게, 로직은 클라우드에. 이 감각을 잡았으니 다음 E-ink 메모장이나 타이핑 머신 프로젝트도 훨씬 매끄럽게 굴러갈 것 같다.
